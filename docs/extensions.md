# Extensions

Extensions are optional features you can install from the internet. They can be toggled on or off in (System)[app:system] → [Extensions](app:extensions) menu.

## How to install one

Install one from the 

An extension runs code on your machine, so install ones you trust.

## Removing one

Uninstall removes the folder and anything the extension saved. Switching it off instead keeps both, so you can turn it back on later.

## When one asks you to wait

An extension can hold your next turn while it finishes something. The composer says what it's waiting for and the send button is disabled until it's done. Switching the extension off releases it immediately.

## When one won't start

An extension that can't run says why in its row. Usually it needs something that isn't there yet — a file still downloading, or a version of freedungeon newer than yours.
